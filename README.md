# TITMAS Ecosystem Connectors

TITMAS Ecosystem Connectors provides contribution points for the AI agent ecosystem.

This repository is for:

- Agent framework adapters
- Protocol integrations
- Community contributions

## Phase 1 Priority

1. MCP
2. LangChain
3. OpenAI Agents SDK
4. CrewAI

## Repository Layout

- `mcp/` MCP adapters and references
- `langchain/` LangChain adapter paths
- `openai-agents/` OpenAI Agents SDK integration paths
- `crewai/` CrewAI integration paths
- `examples/` Shared usage examples
- `docs/` Connector guidance and contribution notes

## Contributing

This repository is for entry and integration scaffolding.
Core runtime and verification capabilities remain in:

- `agent-evidence`
- `SAEE`
- `aro-audit`

We keep the structure lightweight while preserving compatibility with existing upstreams.
